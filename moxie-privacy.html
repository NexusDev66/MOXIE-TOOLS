LEGAL · PRIVACY POLICY

隐私政策

MOXIE 是由独立团队运营的 AI 选型决策平台。我们尽量少收集信息、用最朴素的方式使用，绝不卖给第三方。本政策说明我们如何处理你的个人信息。

1. 我们收集哪些信息

MOXIE 仅在以下三个场景收集你的个人信息：

1.1 浏览榜单

未登录用户可以自由浏览全部产品榜单。在这种状态下，我们 不收集任何个人身份信息。我们仅通过匿名 Cookie 记录页面访问情况以改善产品体验（详见第 4 节）。

1.2 邮件订阅周报

当你在网站输入邮箱订阅 MOXIE 周报时，我们收集：

  • 邮箱地址
  • 订阅日期
  • 订阅来源页面

1.3 注册账号 / 提交产品 / 商业合作

当你注册账号、提交产品或填写商业合作表单时，我们会按表单字段收集：姓名 / 邮箱 / 公司 / 角色 / 联系方式（微信、Telegram 等）、具体需求描述等。所有字段均在表单上明确标注，必填字段标有 *。

MOXIE 助手对话内容仅在你的浏览器和我们的实时匹配 API 之间传输，不会被保存、不会用于训练任何模型、不会被分析用户画像。会话结束即销毁。

2. 我们如何使用信息

信息类型用途是否分享
邮箱地址（周报）发送 MOXIE 周报否
账号信息登录验证、个性化体验否
产品提交信息审核 + 公开展示公开展示
商务联系方式合作对接仅内部商务
匿名访问统计改善产品体验聚合后用于内部分析

我们 永远不会：

  • 把你的邮箱卖给广告商或数据公司
  • 未经允许给你发送营销邮件（订阅周报除外）
  • 在产品中插入第三方追踪代码（Google Ads / Facebook Pixel 等）
  • 跨网站追踪你的行为

3. 第三方与数据共享

MOXIE 仅与以下经过审核的第三方服务商共享必要信息：

  • 邮件服务（如 Resend / Mailchimp）：用于发送周报，仅传输邮箱地址
  • 支付服务（如 Stripe / 微信支付）：处理订阅付款，仅传输金额和订单 ID
  • 云服务商（如 AWS / 阿里云）：托管网站和数据库
  • AI 模型 API（如 OpenAI / DeepSeek）：处理 MOXIE 助手对话请求，对话内容实时处理后销毁

我们 不会把你的个人信息出售或租借给任何第三方用于营销目的。

4. Cookie 与本地存储

MOXIE 使用以下 Cookie 和浏览器本地存储（localStorage）：

名称类型用途保留期
moxie-voteslocalStorage记录你给产品的点赞永久（手动清除前）
moxie-sessionCookie登录态保持30 天
moxie-preflocalStorage页面偏好设置永久
匿名统计 CookieCookie聚合访问统计13 个月

你可以在浏览器设置中清除上述所有数据。清除后部分功能（如已点赞标记、登录态）会重置。

5. 数据安全与保留

我们采取行业标准的安全措施保护你的信息：

  • 全站强制 HTTPS 加密传输
  • 密码使用 bcrypt 单向加密存储
  • 数据库定期备份并加密
  • 仅核心团队（3 人）有权访问生产环境数据

保留期限：账户信息在你注销账号后立即删除；周报订阅信息在你退订后立即从订阅列表移除（但会保留邮箱哈希值 12 个月以防误退订）；匿名访问统计聚合后保留 24 个月。

6. 你的权利

根据相关法律法规（包括 GDPR、PIPL），你享有以下权利：

  1. 访问权：随时查看我们保存的关于你的所有信息
  2. 更正权：要求我们更正不准确的信息
  3. 删除权：要求我们删除你的所有数据（注销账号）
  4. 导出权：以 JSON 格式导出你的全部数据
  5. 退订权：随时退订周报（邮件底部一键退订链接）

行使上述权利请发邮件至 privacy@moxie.com，我们会在 7 个工作日内处理。

7. 未成年人保护

MOXIE 不面向 14 周岁以下未成年人。我们不会主动收集 14 周岁以下未成年人的个人信息。如发现误收集，请联系我们立即删除。

8. 政策更新与联系

如本政策有实质性变更，我们会通过以下方式通知：

  • 提前 30 天在本页面顶部显著位置公告
  • 向注册用户发送邮件通知
  • 更新本页面顶部的「最近更新」日期

对本政策有任何疑问，请联系：

  • 邮箱：privacy@moxie.com
  • 商务：hello@moxie.com
  • 邮寄地址：北京市朝阳区 XXX（如需）
本政策的最终解释权归 MOXIE 团队所有。
