常见问题

排名变了徽章会自动更新吗？

会。徽章引用的是 MOXIE 服务器上的实时 SVG，你的产品排名变化、票数增加，所有挂在外部的徽章会自动同步刷新。零维护。

能不能换字体 / 改颜色？

当前 4 款是官方版本。如果你的网站调性差异大，复制 SVG URL → 下载 → 改源码自托管也可以，但失去自动同步。我们后续会出可定制版（PRO 等级）。

贴到哪儿效果最好？

① 官网底部 footer（持续曝光）② 关于页 / 团队页（可信背书）③ Twitter pinned tweet（拉新场景）④ GitHub README 顶部（开发者社区）。

会跟踪到点击吗？

会。点击徽章回流 MOXIE 的访问者，会带 ?ref=badge 参数，你能在 Maker 后台看到每天有多少人通过你的徽章回流（即将上线）。

没看到我的产品怎么办？

说明你的产品还没在 MOXIE 收录。提交产品 → 编辑团队 48h 内审核。
