# 开发路线图

原则:**小步推进,每一步都"部署 + 线上可验"才进下一步**。不囤代码。每个 Phase 上线后能看到真实进展。

图例:✅完成 / 🚧进行中 / ⬜待办

---

## Phase 0 · 头部数据上线(让站立刻有真内容)
目标:静态站首页/分类页能看到几十个**真实有价值**的工具。
- ✅ 0.1 头部种子清单 `cli/seed-tools.json`(44 个国产+海外工具,覆盖 10 分类)
- ✅ 0.2 入库脚本 `cli/seed-products.js`(幂等 upsert → `moxie_products` status=published)
- ⬜ 0.3 你在 `.env.local` 填 `SUPABASE_SERVICE_ROLE_KEY` → 跑 `node --env-file=.env.local cli/seed-products.js --dry-run` 预览 → 去掉 `--dry-run` 实插
- ⬜ 0.4 起静态站(本地或线上)确认首页/分类页能看到这些工具
- **DoD**:线上 published 产品 ≥ 50(原 12 + 新 44),静态站可见、分类正确。

## Phase 1 · SEO 预渲染(线上 sitemap 不再 404)
目标:爬虫能看到产品/文章内容。
- ⬜ 1.1 预渲染脚本 `cli/prerender.js`:读库 published 产品/文章 → 套 `moxie-product.html`/`moxie-article.html` 模板烤数据 + `<title>/<meta>/canonical` + JSON-LD
- ⬜ 1.2 生成 `sitemap.xml`(产品+文章+分类 URL)
- ⬜ 1.3 接进部署(每次数据变化后重渲染)
- **DoD**:线上 `sitemap.xml` 可访问;某产品详情页"查看源代码"能看到正文 + JSON-LD。

## Phase 2 · 权重算法 + 定时排序
目标:产品按价值自动排序,每天更新。
- ⬜ 2.1 迁移:`moxie_products.weight_score`(+ 必要的流量列)
- ⬜ 2.2 `cli/rank.js`:weight = 流量(SimilarWeb)+ 时效 + 完善度 + 编辑加权,写回 weight_score
- ⬜ 2.3 静态 UI 排序字段改 `weight_score`(vote_count 兜底)
- ⬜ 2.4 GitHub Actions 每日 cron 跑 rank + 重渲染
- **DoD**:cron 有运行记录;排序随权重变化;头部是高价值工具。

## Phase 3 · 新锐自动管道(全自动 + 门槛)
目标:持续自动发现并入库**过质量门槛**的新工具。
- ⬜ 3.1 抓取(复用 scanner)→ 候选
- ⬜ 3.2 AI 清洗补全(复用 enrichment)
- ⬜ 3.3 权重 + 流量门槛:过阈值才自动 published,junk 留 pending
- ⬜ 3.4 cron 串起来;遇已存在 domain 只链接不覆盖(复审 #13 教训)
- **DoD**:cron 自动新增的产品都是有价值的,无人工干预。

## Phase 4 · SEO 文章自动化
目标:定时自动产出 published SEO 长文并被收录。
- ⬜ 4.1 文章生成(复用 article-gen)从高价值产品出横评/趋势文
- ⬜ 4.2 触发(定时 + 类目积累)→ published 文章
- ⬜ 4.3 文章预渲染 + sitemap 更新 + (可选)GSC 提交
- **DoD**:线上有自动生成的文章页,源代码含内容 + JSON-LD,进 sitemap。
