# 文档索引

本目录是 latemai 数据闭环项目的**权威标准文件**。开工前先读这里。

## 当前标准文件(权威)
| 文件 | 作用 | 何时读 |
|---|---|---|
| [需求规格.md](需求规格.md) | 项目要做什么、为什么、验收口径 | 不清楚目标时 |
| [技术架构.md](技术架构.md) | 架构、数据契约(库表)、技术选型 | 写代码前 |
| [设计规范.md](设计规范.md) | 编码 / 安全 / 部署红线 | 写代码前 + 每次提交前 |
| [开发路线图.md](开发路线图.md) | 分阶段执行步骤 + 每步验收 | **每次开工第一件事** |

## 工作流
1. 开工:读 `开发路线图.md` 看当前 Phase + 下一小步;读 `../开发日志/` 最新一天看上次进度。
2. 做:**一次只做一小步**,遵守 `设计规范.md`。
3. 收工:更新当天 `../开发日志/YYYY-MM-DD.md`(完成 / 待办 / 阻塞)。
