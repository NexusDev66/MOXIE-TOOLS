风评

综合风评
webclaw 是一个基于 Rust 构建的本地优先网页内容提取工具，专注于为 LLM 提供结构化数据。它支持抓取、爬取和结构化提取，并提供 CLI、REST API 和 MCP 服务器三种接口，适合需要将网页内容直接输入给语言模型的场景。由于数据在本地处理，无需上传至云端，对隐私敏感的用户较为友好。
该工具主要面向需要高效、可控地获取网页结构化数据的开发者或 LLM 应用构建者。其 Rust 实现保证了抓取性能，但使用前需具备一定的命令行或 API 调用基础。国内可直接访问，无额外限制。具体定价模式需参考官方文档，通常提供免费额度或开源版本。
