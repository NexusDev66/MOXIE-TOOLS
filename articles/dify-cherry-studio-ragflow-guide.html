Dify 怎么用？从零开始的 Dify 教程与使用技巧

本文提供 Dify 上手手册，涵盖安装、工作流搭建、RAG 配置及常见坑，助你快速掌握 Dify 使用技巧。

Dify 怎么用？快速入门

Dify 是一款开源的一站式 LLMOps 平台，支持可视化编排智能体、RAG 流水线和模型管理。本 Dify 教程将带你从零开始，掌握核心操作与 Dify 使用技巧。

安装与部署

Dify 支持 Docker 一键部署，适合团队本地化运行。建议使用官方 Docker Compose 文件，确保网络环境可访问 Docker Hub。部署后通过 http://localhost:3000 访问，首次需设置管理员账号。

创建第一个智能体

登录后，点击“创建应用”选择“智能体”。在编排界面，拖拽“LLM”节点，选择模型（如 GPT-4 或本地模型），配置提示词。Dify 使用技巧：善用“变量”功能，将用户输入动态注入提示词，提升灵活性。

典型工作流：RAG 知识库问答

集成 RAG 流水线

Dify 内置 RAG 引擎，可上传文档（PDF、TXT 等）构建知识库。在应用设置中启用“知识库”，上传文件后系统自动切分并向量化。Dify 教程提示：调整“分块大小”和“重叠”参数可优化检索效果，一般块大小 500-1000 字符，重叠 50-100 字符。

工作流编排

在“工作流”模式下，添加“知识检索”节点连接 LLM，实现“检索-生成”流水线。Dify 怎么用？先拖拽“开始”节点，连接“知识检索”，再连“LLM 响应”，最后“结束”节点。测试时输入问题，检查检索结果是否相关。

常见坑与最佳实践

模型选择与成本

Dify 支持多模型，但不同模型 API 价格差异大。建议开发阶段使用免费模型（如某些开源模型），生产环境再切换付费模型。Dify 使用技巧：在“模型供应商”中统一管理 API Key，避免泄露。

数据隐私与部署

Dify 可本地化部署，数据完全离线。若需远程访问，配置反向代理（如 Nginx）并开启 HTTPS。注意：Dify 默认不限制 API 调用频率，生产环境需自行添加限流。

常见问题

Dify 怎么用中文界面？

Dify 支持多语言，在用户设置中切换语言为“简体中文”。若未生效，检查浏览器缓存或重新登录。

如何将 Cherry Studio 与 Dify 配合？

Cherry Studio 是本地多模型客户端，可调用 Dify 的 API。在 Cherry Studio 中添加自定义 API，填入 Dify 的地址和密钥，即可在本地使用 Dify 工作流。

RAGFlow 和 Dify 有什么区别？

RAGFlow 专注于深度文档理解的 RAG 引擎，适合企业级知识库；Dify 是更全面的 LLMOps 平台，包含智能体编排和工作流。两者可互补，例如用 RAGFlow 处理复杂文档，再通过 Dify 编排流程。
