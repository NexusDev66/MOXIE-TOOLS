Coze 怎么用？零基础入门指南

Coze 是字节跳动推出的零代码 AI Bot 构建平台，支持工作流编排、知识库集成与多平台发布，国内可直接使用。如果你是第一次接触 Coze，这篇 Coze 教程 将带你快速上手。

1. 注册与创建第一个 Bot

访问 Coze 官网（国内可直接访问），使用手机号或邮箱注册。登录后，点击“创建 Bot”按钮，进入编辑界面。你可以为 Bot 命名、设定身份（如“客服助手”），并编写提示词（Prompt）来定义其行为。Coze 提供了丰富的预设模板，适合新手快速开始。

2. 工作流编排：让 Bot 执行复杂任务

Coze 的核心功能之一是工作流编排。点击“工作流”选项卡，你可以通过拖拽节点构建自动化流程。例如：用户提问 → 调用搜索引擎获取信息 → 用 LLM 总结 → 输出答案。常见节点包括“大语言模型”、“代码执行”、“条件判断”等。注意：工作流中的变量需使用双花括号引用，如 {{input}}。

3. 知识库集成：为 Bot 注入私有数据

Coze 支持上传文档（PDF、Word、TXT 等）或连接在线数据源（如飞书文档）。在“知识库”模块中，你可以创建知识库并添加文件。Bot 在回答时会自动检索相关知识。建议将知识库按主题分类，并定期更新，以提高回答准确性。

4. 多平台发布：一键部署到微信、飞书等

Coze 允许将 Bot 发布到多个平台，包括微信、飞书、Web 等。在“发布”页面，选择目标平台并完成授权即可。注意：发布到微信需要企业认证，个人用户可先使用 Web 版测试。

5. 常见坑与最佳实践

  • 提示词优化：尽量用结构化描述（角色+任务+限制），避免模糊指令。
  • 工作流调试：使用“预览”功能测试每个节点输出，确保变量传递正确。
  • 知识库大小：单个知识库文件数建议不超过 100 个，否则检索效率可能下降。
  • 成本控制：Coze 免费版有调用次数限制，具体价格以官网实测为准。

与 Zapier、n8n 的对比

如果你需要跨应用自动化，可以考虑 Zapier 或 n8n。Zapier 连接 9000+ 应用，但国内使用需代理；n8n 是开源工具，支持自部署，适合技术团队。Coze 的优势在于国内直接可用、零代码门槛，且与字节生态（飞书、抖音）深度集成。

常见问题

Coze 是否完全免费？

Coze 提供免费额度，但高级功能（如更高调用次数、自定义模型）可能需要付费。具体价格以官网实测为准。

Coze 的工作流能调用外部 API 吗？

可以。在工作流中添加“代码执行”节点，使用 JavaScript 或 Python 发起 HTTP 请求。注意需要处理跨域和认证问题。

Coze 与 ChatGPT 的 GPTs 有何不同？

Coze 更侧重工作流编排与多平台发布，适合国内用户；GPTs 依赖 OpenAI 生态，国内访问受限。Coze 还支持飞书、微信等国内常用平台。
