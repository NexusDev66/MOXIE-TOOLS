FastGPT 怎么用：从安装到第一个问答机器人

FastGPT 是一款开源的知识库问答与工作流工具，适合企业或个人快速搭建基于私有知识的 AI 助手。下面我们按步骤讲解 FastGPT 怎么用，从部署到完成一个简单问答流程。

1. 部署与初始化

FastGPT 支持 Docker 一键部署。克隆官方仓库后，执行 docker-compose up -d 即可启动。首次访问需要配置管理员账号和 OpenAI 或其他大模型 API Key。注意：如果国内部署，确保网络能访问 API 或使用国内模型代理。这一步是 FastGPT 教程 的基础，务必确认端口未被占用。

2. 创建知识库

登录后，点击“知识库” -> “新建知识库”。支持上传 PDF、Word、TXT、Markdown 等格式。FastGPT 会自动进行文本分割和向量化。建议：对于长文档，使用“分段”模式并设置合适的 chunk 大小（例如 500 字符），过小会丢失上下文，过大影响检索精度。这是 FastGPT 使用技巧 中非常重要的一点。

3. 配置工作流

FastGPT 的核心是工作流。创建一个“应用”，选择“知识库问答”模板。工作流节点包括：用户输入 -> 知识库检索 -> LLM 生成 -> 输出。你可以添加“问题分类”、“敏感词过滤”等中间节点。例如，在检索节点中，可以设置检索条数（topK）和相似度阈值（0.7 左右效果较好）。保存后即可发布为 API 或 Web 对话界面。

FastGPT 教程：典型工作流详解

以“企业 FAQ 机器人”为例，完整工作流如下：

  • 输入节点：接收用户问题，可做格式清洗。
  • 知识库检索：从已上传的 FAQ 文档中召回最相关的 3-5 段文本。
  • Prompt 组装：将检索结果与问题拼接，并加入系统提示（如“仅根据以下内容回答”）。
  • LLM 调用：调用 GPT-4 或国内模型生成答案。
  • 输出节点：返回答案，并可附加引用来源。

注意：如果答案不准确，可以调整检索参数或增加“重排”节点（需额外配置）。这是 FastGPT 使用技巧 中常见优化手段。

常见坑与最佳实践

坑 1：知识库文档格式不统一

FastGPT 对 PDF 的 OCR 支持有限，如果文档是扫描件，建议先转成文本。最佳实践：统一使用 Markdown 格式，并手动清理多余换行。

坑 2：工作流循环或死锁

如果添加了条件判断节点，请确保有默认路径，否则可能陷入无限循环。调试时可以开启日志模式查看节点输出。

坑 3：API 调用超时

大模型响应慢时，工作流可能超时。建议在 LLM 节点设置超时时间（如 30 秒），并启用重试机制。

对比 RAGFlow 与 Cherry Studio 的使用技巧

RAGFlow：深度文档理解

RAGFlow 专注于复杂文档（如表格、多栏布局）的解析。如果你需要处理大量 PDF 或扫描件，可以先用 RAGFlow 提取结构化内容，再导入 FastGPT 知识库。使用技巧：RAGFlow 的“版面分析”功能可以自动识别标题、段落、表格，导出为 Markdown 后质量很高。

Cherry Studio：本地多模型客户端

Cherry Studio 是一款本地客户端，支持同时连接多个大模型（包括 OpenAI、Claude、本地模型），并内置知识库功能。如果你需要离线使用或对比不同模型回答，Cherry Studio 更合适。使用技巧：在 Cherry Studio 中创建“知识库”时，注意文件大小限制（免费版通常 100MB 以内）。

三者结合：用 RAGFlow 预处理文档，FastGPT 搭建工作流，Cherry Studio 作为前端测试工具，可以构建一个高效的 RAG 系统。

常见问题

FastGPT 怎么用才能提高回答准确率？

首先，确保知识库文档质量高、分段合理。其次，在检索节点适当降低相似度阈值（如 0.6）以召回更多候选，再通过重排模型精排。最后，Prompt 中明确要求“如果找不到答案，请说不知道”。

FastGPT 教程中，工作流调试有哪些技巧？

开启“调试模式”后，可以逐节点查看输入输出。常见问题：变量引用错误（如 {{query}} 拼写）、节点未连接。建议先使用模板，再逐步修改。

FastGPT 使用技巧：如何与 RAGFlow 协同？

RAGFlow 提供 REST API，可以将其文档解析结果作为 FastGPT 知识库的预处理器。例如，用 Python 脚本调用 RAGFlow 解析 PDF，然后将输出的 Markdown 通过 FastGPT API 上传。具体价格以官网实测为准。
